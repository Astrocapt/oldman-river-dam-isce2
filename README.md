# Oldman River Dam - Sentinel-1 coregistered SLC stack (ISCE2) and SARvey time series

Sentinel-1B descending track 71, IW2, VV, 144 dates (2017-02-26 to 2021-12-14), reference 2017-05-21.
Processed on ASF OpenSARlab: ISCE2 topsStack (slc workflow, NESD) -> MiaplPy load_data (slcStack.h5, geometryRadar.h5) -> SARvey.

- `notebooks/`: the notebooks and environment files
- `results/`: logs, ESD shifts, figures, SARvey outputs
- Large files (slcStack.h5 ...): see the Zenodo link below
